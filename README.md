# pmdrTimer — 포모도로 타이머

집중 시간, 짧은 휴식, 긴 휴식을 직접 설정하고 할 일까지 관리하는 포모도로 타이머입니다.

- 집중 / 짧은 휴식 / 긴 휴식 시간 설정, 몇 사이클 뒤 긴 휴식을 줄지 설정
- 간단한 플래너 (할 일 추가, 완료 체크, 삭제)
- "공부 세션 종료" 시 총 집중 시간 · 휴식 시간 · 완료 사이클 통계
- 집중 시작음(비행기 안전벨트 착용 사인 같은 종소리)과 휴식 시작음을 다르게 재생하고, 알림음 볼륨을 설정에서 조절 (미리 듣기 제공)
- 집중 중에는 설정을 접고 그 자리에 미국 위인들의 명언을 표시
- 기본 테마는 라이트이며, 타이머 카드 오른쪽 위 버튼으로 라이트/다크 전환 (선택은 저장됨)
- 설정과 할 일은 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다

## 구성

| 경로 | 설명 |
|------|------|
| `docs/index.html` | 웹 배포용 단일 파일 (GitHub Pages가 이 폴더를 공개합니다) |
| `포모도로 타이머.exe` | Windows용 실행 파일 (Edge/Chrome 앱 창으로 실행) |
| `src/` | 소스 (`index.html`, `Launcher.cs`)와 exe 빌드 스크립트 `build.ps1` |

## Windows exe 다시 빌드

```powershell
powershell -ExecutionPolicy Bypass -File src\build.ps1
```

Windows에 기본 포함된 .NET Framework 컴파일러를 사용하므로 별도 설치가 필요 없습니다.
